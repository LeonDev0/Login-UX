Concepto de inicio de sesion
Un concepto de inicio de sesión enfocado en la experiencia de usuario y diseño visual, utilizando Anime.js para animaciones de entrada y Glassmorphism para la interfaz.

Características principales
-Validación de contraseña: Barra de seguridad dinámica con lógica de 5 niveles (incluyendo bonus por longitud y caracteres especiales).

-Animaciones: Entrada en cascada (stagger) para el título y preloader de carga inicial.

-Diseño visual: Fondo con gradientes dinámicos y efecto de olas animadas mediante SVG parallax.

-Responsive: Adaptado para dispositivos móviles y escritorio.

Tecnologías utilizadas
*HTML5 / CSS3 
*JavaScript
*Anime.js para la lógica de animaciones.

Instalación y uso
Clona el repositorio:
git clone https://github.com/
Abre index.html en tu navegador (se recomienda usar Live Server en VS Code).
